# Sydney · Иггдрасиль

Личный сайт со скроллителлингом в 3D. Листаешь вниз, камера спускается по Мировому древу: крона под северным сиянием и двумя лунами (лучи света сквозь ветви), море облаков, Мидгард с горами, нить Норн вокруг ствола, корни и светящийся источник Урд.

Чистый HTML/CSS/JS, без сборки. three.js 0.160.0 лежит в `vendor/three` (лицензия MIT в `vendor/three/LICENSE`), CDN не нужен.

## Деплой на GitHub Pages

1. Залить в корень репозитория: `index.html`, `style.css`, `content.json`, `content.js`, `ui.js`, `admin.js`, `scene.js`, `favicon.svg`, `.nojekyll`, папку `vendor/`. Папка `.claude/` для сайта не нужна.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<username>.github.io/<repo>/`.

Локально открывать через сервер (модули не работают с `file://`):

```
python -m http.server 5173
```

## Админка

Открыть: `Ctrl+Shift+F` или 5 быстрых кликов по рунам над именем.

- **Применить**: черновик только в этом браузере.
- **Опубликовать**: коммитит `content.json` в репозиторий через GitHub API, Pages обновится за 1–2 минуты.
- **Скачать JSON** / **Сбросить черновик**.

Для публикации нужен fine-grained токен: GitHub → Settings → Developer settings → Fine-grained tokens → доступ только к репозиторию сайта, Permissions → Contents: Read and write. Токен хранится только в браузере, где его вставили.

## Где что менять

- Тексты, ссылки, рунные камни: `content.json` (или админка); `index.html` хранит запасной текст на случай, если JSON не загрузится
- Цвета, шрифты, панели: `style.css`
- 3D: `scene.js` (`KEYS` путь камеры по главам, `FOG` туман, шейдер неба с сиянием, дерево, лучи `godrays`)
- Шкала с Рататоском, камни, руны в источнике: `ui.js`
